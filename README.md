# Variant Effect Explorer

Interactive 3D map of disease-causing vs benign protein variants, scored by a protein
language model (ESM-1v) and benchmarked against AlphaMissense.

> 🚧 Work in progress — demo, results and screenshots coming soon.

## Stack
Python (Biopython, PyTorch, fair-esm) · ClinVar · AlphaFold DB · TypeScript · Mol* · Vite
